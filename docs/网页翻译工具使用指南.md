# 网页翻译工具使用指南

`dolp-kit-translation-editor.html` 是一个**本地、离线**的网页翻译编辑器。用
Chrome / Edge 直接打开这个文件即可，不需要安装、不需要服务器，所有文件只在
你的浏览器里处理，不会上传网络。

它只做一件事：读取 Toolkit 导出的 `localization-kit.zip`，让你填写
`translation`，检查结构，导出新的 ZIP / JSONL，再交回
`node core/src/run.mjs kit import`。**它不生成译文。**

## 1. 基本流程

1. 用 Toolkit 导出一个 Kit：

   ```bash
   node core/src/run.mjs kit export --story <index.html> --output _work/kit.zip --scope all
   ```

2. 打开 `dolp-kit-translation-editor.html`，点“打开 ZIP”或把 `kit.zip` 拖进页面。
3. 逐条阅读原文、填写译文。原文里的 `⟦0⟧`、`⟦1⟧` 等占位符**必须原样保留**，
   数量与顺序都要与原文一致。
4. 点“导出汉化 ZIP”（或“另存 JSONL”）保存结果。
5. 回到 Toolkit 导入并构建：

   ```bash
   node core/src/run.mjs kit import _work/kit-translated.zip --story <index.html> --out _work/state.jsonl
   ```

## 2. 界面分区

* **顶部工具栏**：打开 ZIP、导出汉化 ZIP、另存 JSONL、界面语言、关键词词典。
* **概览区**：进度条与统计（总条目、已翻译、未翻译、完成度、待校对、已校对、
  存疑、安全问题数）。
* **工程操作区**：导入 / 导出编辑工程、迁移新版本译文、清除本机草稿。
* **筛选工具栏**：搜索 + 筛选 + 术语框 + 排序 + 每页条数 + 字号 + 深色模式。
* **编辑工具栏**：撤销、重做、安全检查、术语检查、重复原文、冲突、批量标记。
* **编辑区**：每条包含原文、译文、复制原文、替换关键词、占位符提醒，以及
  状态标记与备注。

## 3. 编辑与校对

* **复制单条 / 全部原文**：只把原文当起点填进译文框；复制不会改动原文，
  未翻译的原文在最终导入时可能被 Toolkit 拒绝。“复制全部原文”是一次
  完整的批量操作，可用一次撤销 / 重做还原。
* **替换关键词**：使用“关键词词典”里的词条替换当前译文，英文词条按完整
  单词、区分大小写匹配。不会自动替换原文、整个 Kit 或其他译文。
* **状态标记**：未标记 / 待校对 / 已校对 / 存疑，另可填一段简短备注。
  状态与备注**只**保存在编辑工程和浏览器草稿里，不会写进游戏翻译包。
* **批量标记**：先用筛选选出目标条目，再在编辑工具栏选择状态、点“标记当前结果”。
* **撤销 / 重做**：编辑工具栏的按钮，或 `Ctrl+Z` / `Ctrl+Shift+Z`
  （`Ctrl+Y` 亦可）。单条编辑、复制、术语替换、批量导入、状态标记都作为
  一组操作撤销。在译文输入框内，`Ctrl+Z` 仍然使用浏览器自带的逐字撤销。

## 4. 搜索与筛选

搜索会匹配原文、译文、场景、条目 ID 和备注。筛选支持：全部条目、未翻译、
已翻译、待校对、已校对、存疑、存在安全问题、占位符提醒、包含指定术语、
存在翻译冲突、存在重复原文。搜索、筛选、排序、分页统一为
“原始数据 → 搜索 → 筛选 → 排序 → 分页”，**不会**改变条目之间的对应关系。

## 5. 分页导航

列表顶部和底部各有一套完全同步的分页导航（共享同一页码状态）：

* 最多显示 9 个连续页码，当前页尽量居中（左右各 4 页），靠近首页 / 末页时
  自动调整范围；总页数少于 9 页时显示全部页码。
* 当前页高亮显示；保留“上一页 / 下一页”。
* 右侧数字输入框可直接跳页：输入页码后点“跳转”或按 Enter；超出范围会自动
  收敛到存在的页面。
* 切换页码前会先提交正在编辑的译文，翻页不会丢失输入内容，也不会串位。
* 分页与搜索、筛选、排序、每页条数联动；改变条件后当前页会自动修正。

## 6. 检查面板

* **安全检查**：比对占位符数量 / 顺序 / 匹配，以及译文里意外出现的宏、变量、
  HTML 标签、链接。可以只检查当前条目或全部条目，点“定位”跳到对应条目。
  只提示，**不会修改任何译文**。
* **术语检查**：根据关键词词典，检查原文出现的术语是否按词典翻译，给出推荐
  译法，可以定位、忽略单条提醒，或在确认后执行替换。
* **重复原文**：把保护后原文完全相同的条目分组，显示出现次数与已有译文；
  若同组存在不同译文会提示。提供“用已有译文填充空白条目”（只填空白，可撤销）。
* **冲突**：导入已有译文时，若与当前译文不同，会在这里逐条预览与选择。

> 检查里的“警告/提示”不一定代表错误：同一个英文词可能有多种合法译法，同一句
> 原文也可能因人物、语境、性别、变量或剧情状态而需要不同译文。请自行判断。

## 7. 关键词词典

词典保存在浏览器 IndexedDB，独立于 Kit，也不会随 ZIP 导出。浏览器清理数据或
更换浏览器可能丢失，请定期用“导出词典 JSON”备份。导入词典时会把同名词条合并
并覆盖。

## 8. 数据放在哪里

* 游戏翻译数据：`kit.zip` 里的 `segments.jsonl` / `segments.csv`，由你把导出的
  ZIP / JSONL 交回 Toolkit。
* 编辑工程与状态：浏览器草稿，以及你手动导出的 `*.dolpkit.json` 工程文件。
* 检查报告：只在界面里显示，不自动写文件。

详见 [翻译数据安全与恢复说明](翻译数据安全与恢复说明.md)。

## 9. 常见问题

* **打开 ZIP 报错**：确认是 Toolkit 导出的 `localization-kit.zip`，且
  `manifest.kind` 为 `dol-p-localization-kit`。单包建议 200～5000 条，超过
  30000 条请用 Toolkit 的分片导出。
* **导入被 Toolkit 拒绝**：常见原因是占位符数量或顺序不一致、改动了宏 / 变量 /
  标签。用“安全检查”定位后修正译文。
* **界面语言**：右上角“界面语言”可在中文 / English 之间切换。
